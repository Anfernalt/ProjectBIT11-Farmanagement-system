# ระบบจัดการฟาร์มโคนม (Prototype)

เว็บ prototype สำหรับทดลอง workflow จัดการโค รีดนม สุขภาพ/ผสมพันธุ์ ผู้ใช้ และคุณภาพน้ำนม โดยเก็บข้อมูลใน MySQL ผ่าน Express API

## เริ่มด้วย Docker

ต้องติดตั้ง Node.js 20 ขึ้นไป และ Docker Desktop ก่อน

```powershell
Copy-Item .env.example .env
npm install
docker compose up -d
npm start
```

เปิดเว็บที่ <http://localhost:3000> แอปจะรอ MySQL พร้อมสูงสุด 30 วินาที จากนั้นสร้างฐานข้อมูล ตาราง และข้อมูลตัวอย่างให้อัตโนมัติในครั้งแรก

หยุด MySQL ด้วย `docker compose down` ข้อมูลจะยังอยู่ใน Docker volume สำหรับการทดลองครั้งถัดไป

## ใช้ MySQL ที่ติดตั้งอยู่แล้ว

ติดตั้ง/เปิด MySQL 8 ขึ้นไป จากนั้นคัดลอก `.env.example` เป็น `.env` และตั้ง `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD` ให้ตรงกับเครื่อง MySQL ผู้ใช้ฐานข้อมูลต้องมีสิทธิ์สร้าง database และ tables แล้วรัน:

```powershell
npm install
npm start
```

ค่าเริ่มต้นของฐานข้อมูลคือ `dairy_farm` และปรับได้ด้วย `MYSQL_DATABASE`

ตรวจการเชื่อมต่อได้ที่ <http://localhost:3000/api/health>

## ขอบเขต prototype

- การเพิ่ม/แก้ไขโค, บันทึกรีดนม, ประวัติสุขภาพ/ผสมพันธุ์, ผู้ใช้งาน/สิทธิ์, ข้อมูลฟาร์ม, การตั้งค่าแจ้งเตือน และข้อมูลคุณภาพน้ำนมถูกบันทึกใน MySQL
- การนำเข้าใบสรุปยังเป็นการจำลอง OCR: เลือกไฟล์แล้วตรวจ/แก้ค่าตัวอย่างก่อนบันทึก ขณะนี้ยังไม่ได้เชื่อม OCR จริง
- หน้าจัดการผู้ใช้เป็นข้อมูลตัวอย่าง ยังไม่มีระบบ login, password หรือ authorization จริง จึงเหมาะสำหรับทดลองในเครื่องเท่านั้น
- อย่าใช้รหัสผ่านใน `.env.example` กับระบบจริง และอย่าเปิด port ของ prototype สู่เครือข่ายสาธารณะ
